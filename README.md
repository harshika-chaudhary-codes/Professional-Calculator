# Professional Calculator

A responsive professional calculator built using HTML, CSS and JavaScript.

## 🌐 Live Demo

[Open Calculator](https://professional-calculator-peach.vercel.app/)

## ✨ Features

- Standard calculator operations
- Scientific calculator
- Trigonometric functions
- Logarithmic functions
- Factorial and percentage
- Calculation history
- Keyboard support
- Responsive design
- Professional dark blue and white UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
